# NeuroScribe Documentation

This directory contains the maintained project documentation. Historical implementation records are kept under archive/ so the main documentation remains readable.

## Maintained documentation

- Architecture — docs/architecture.md
- Development — docs/development.md
- Product / MVP scope — docs/product/mvp-scope.md
- Database schema — docs/architecture/database.md
- UI integration plan — docs/design/ui-integration.md
- Security — SECURITY.md
- Security verification — docs/security/
- Operations — docs/operations/

## Documentation rule

New documentation should describe the current implementation. Time-specific implementation logs, one-off audits, migration notes, and superseded designs belong in docs/archive/.
